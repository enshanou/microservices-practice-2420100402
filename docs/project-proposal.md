# 课览 CourseLens：项目选题简案

## 项目与目标用户

课览是一款面向视频课程的预习与可编辑笔记工作台。目标用户是需要学习高校课程、技术教程或岗位培训视频的学生与自学者，处理的素材限于本人有权使用的视频、音频或字幕。

## 优先业务场景

学习者导入一门课程后，系统在后台处理素材，并让学习者看到处理状态。处理完成后，学习者先阅读课程概览、章节和关键关注点，再进入学习页，依据带来源定位的 AI 笔记初稿观看和修订。这一场景对应仓库 README 中的“预览 → 观看 → 修订 → 复习”闭环。

## 计划中的两个核心模型

| 模型 | 主要职责 | 关键关系 |
| --- | --- | --- |
| 课程（Course） | 表示学习者导入的课程及其归属、标题和素材入口 | 一门课程归属一名学习者，可关联多次处理记录 |
| 处理任务（ProcessingTask） | 跟踪转写、内容生成等异步步骤的状态、失败阶段与重试 | 一条任务归属一门课程，可包含多次处理尝试 |

本周仅确认模型方向，不实现业务模型或数据库。第三周交付范围是可运行的 Spring Boot 工程、问候接口、健康检查和启动测试。
